Ein **React Playground** in Form einer **League of Legends Team-Maker Web-App**.  
Die Anwendung ermöglicht es, **zwei Teams zu erstellen**, **Spieler hinzuzufügen** und (ehemals) mithilfe einer **KI faire Teams basierend auf Spieler-Daten** zu generieren.

Das Projekt dient sowohl als **Lern- & Experimentierumgebung** als auch als **Funktions-Prototyp**.

---

## Tech Stack

- **React**
- **Vite**
- **Tailwind CSS**
- **JavaScript (ESM)**

---

## Projektidee

Ziel des Projekts war es, eine einfache Web-App zu entwickeln, mit der man:

-  Spieler manuell hinzufügen kann
-  Zwei League-of-Legends-Teams erstellt
-  Spieler anhand von Daten bewertet
-  *automatisch faire Teams* erstellen lassen kann

Die App ist als **Playground** konzipiert und nicht als fertiges Produkt.

---

## Features

### Aktuelle 
- Manuelles Erstellen von **Team 1** und **Team 2**
- Hinzufügen von Spielern
- Übersichtliche Team-Darstellung
- Schnelles UI durch React + Vite
- Styling mit Tailwind CSS

### Frühere Features (nicht mehr aktiv)
- **KI-basierte Team-Generierung**
  - Analyse von Spieler-Daten (z. B. Skill / Stats)
  - Automatische Aufteilung in **zwei möglichst ausgeglichene Teams**
  - Fokus auf Fairness & Balance

> Die KI-Logik wurde im Rahmen von Experimenten implementiert und später wieder entfernt bzw. deaktiviert.
